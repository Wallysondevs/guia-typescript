Funções Tipadas

Funções são onde o TypeScript mais ajuda. Você diz o que a função recebe e o que ela devolve, e o compilador confere cada chamada: número certo de argumentos, tipos certos, retorno usado do jeito certo.

Você vai aprender
  • A tipar parâmetros e retorno: function soma(a: number, b: number): number.
  • Os erros de chamada: argumento a mais, a menos ou do tipo errado.
  • Arrow functions tipadas.
  • O tipo de uma função, (n: number) => number, e callbacks.

1. Parâmetros e retorno

function media
o nome da função
(a: number, b: number)
os parâmetros, cada um com o seu tipo
: number
o tipo do retorno (opcional: seria inferido)
function media(a: number, b: number): number {
  return (a + b) / 2;
}

function saudacao(nome: string, hora: number): string {
  if (hora < 12) return `Bom dia, ${nome}!`;
  return `Boa tarde, ${nome}!`;
}

console.log(media(7, 10));
console.log(saudacao("Ana", 9));
console.log(saudacao("Duda", 15));
$ npx tsc && node dist/funcoes.js
8.5
Bom dia, Ana!
Boa tarde, Duda!

Escrever o retorno (: number) é opcional, mas ajuda: se você esquecer um return ou devolver o tipo errado, o erro aparece dentro da função, e não lá longe, onde ela é usada.

function nota(valor: number): string {
  if (valor >= 7) {
    return "aprovado";
  }
}
$ npx tsc
src/retorno.ts(1,31): error TS2366: Function lacks ending return statement and return type does not include 'undefined'.

O TS2366 avisa: se valor for menor que 7, a função termina sem devolver nada, e o retorno prometido era string.

2. O compilador confere cada chamada

function media(a: number, b: number): number {
  return (a + b) / 2;
}

media(7);
media(7, 8, 9);
media(7, "8");
$ npx tsc
src/chamadas.ts(5,1): error TS2554: Expected 2 arguments, but got 1.
src/chamadas.ts(6,13): error TS2554: Expected 2 arguments, but got 3.
src/chamadas.ts(7,10): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.

Três chamadas, três erros: TS2554 para a quantidade de argumentos (faltando ou sobrando) e TS2345 para o tipo errado. No JavaScript puro, todas rodariam caladas.

3. Arrow functions

As funções de seta (=>) recebem tipos do mesmo jeito:

const dobro = (n: number): number => n * 2;
const ehPar = (n: number) => n % 2 === 0;

console.log(dobro(8));
console.log(ehPar(8), ehPar(7));

const numeros = [1, 2, 3, 4];
console.log(numeros.map((n) => n * 10));
console.log(numeros.filter(ehPar));
$ npx tsc && node dist/arrow.js
16
true false
[ 10, 20, 30, 40 ]
[ 2, 4 ]

Repare no map((n) => n * 10): o n não tem anotação, mas não deu erro. Como numeros é number[], o TypeScript sabe que o n do callback é number. Isso se chama tipagem pelo contexto.

4. O tipo de uma função

Uma função também pode ser o tipo de uma variável ou de um parâmetro. Escreve-se como uma arrow: (parâmetros) => retorno.

type Operacao = (a: number, b: number) => number;

const somar: Operacao = (a, b) => a + b;
const multiplicar: Operacao = (a, b) => a * b;

function calcular(x: number, y: number, op: Operacao): number {
  return op(x, y);
}

console.log(calcular(6, 7, somar));
console.log(calcular(6, 7, multiplicar));
console.log(calcular(6, 7, (a, b) => a - b));
$ npx tsc && node dist/tipo-funcao.js
13
42
-1

O type Operacao = … dá um nome ao tipo (aula Objetos e type). Uma função que não combina com Operacao é recusada:

type Operacao = (a: number, b: number) => number;
const juntar: Operacao = (a, b) => `${a}${b}`;
$ npx tsc
src/tipo-funcao-erro.ts(2,36): error TS2322: Type 'string' is not assignable to type 'number'.

Quando dá errado

Usar o retorno de uma função void 
function mostrar(msg: string): void {
  console.log(msg);
}
const r = mostrar("oi");
console.log(r.length);
$ npx tsc
src/void.ts(5,15): error TS2339: Property 'length' does not exist on type 'void'.

Quem devolve void não devolve nada útil; o compilador não deixa usar o “resultado”.

Chamar algo que não é função 
const total = 10;
total();
$ npx tsc
src/nao-funcao.ts(2,1): error TS2349: This expression is not callable.
  Type 'Number' has no call signatures.

Resumo

  • Parâmetros sempre com tipo; retorno opcional, mas recomendado.
  • O compilador confere quantidade e tipo dos argumentos (TS2554, TS2345).
  • Arrow functions são tipadas do mesmo jeito; callbacks pegam o tipo pelo contexto.
  • O tipo de uma função se escreve (a: number) => number.
