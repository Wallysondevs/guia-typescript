Erros comuns e como ler

Você já viu dezenas de erros ao longo do guia. Esta aula junta os mais frequentes num lugar só e ensina a ler a mensagem como um profissional: onde está o problema, qual é o código dele e o que a frase em inglês está dizendo. As mensagens ficam em inglês aqui, exatamente como o tsc mostra, para você reconhecê-las no seu terminal.

Você vai aprender
  • As partes de uma linha de erro do tsc.
  • Os erros de tipo mais frequentes e a correção de cada um.
  • Erros de sintaxe e de nomes.
  • Uma estratégia para quando aparecem muitos erros de uma vez.

4. Erros de sintaxe

Erros com código TS1xxx costumam ser de sintaxe: o texto nem chega a ser um programa válido.

const nomes = ["Ana", "Duda";
function ola( {
  console.log("oi");
}
$ npx tsc
src/sintaxe.ts(1,29): error TS1005: ',' expected.
src/sintaxe.ts(3,10): error TS1005: ',' expected.
src/sintaxe.ts(3,14): error TS1005: ',' expected.
src/sintaxe.ts(4,1): error TS1128: Declaration or statement expected.

Em erros de sintaxe, a linha apontada às vezes é depois do problema real: o compilador só percebe que algo faltou quando encontra o próximo símbolo. Olhe a linha indicada e a anterior.

Quando dá errado: muitos erros de uma vez

Um erro que gera vários

Um único engano pode disparar uma cascata de mensagens. Aqui, o tipo Produto foi escrito com p minúsculo na declaração:

type produto = { nome: string; preco: number };

const a: Produto = { nome: "Lápis", preco: 2 };
const b: Produto = { nome: "Caderno", preco: 15 };
function total(itens: Produto[]): number {
  return itens.reduce((s, p) => s + p.preco, 0);
}
console.log(total([a, b]));
$ npx tsc
src/cascata.ts(3,10): error TS2552: Cannot find name 'Produto'. Did you mean 'produto'?
src/cascata.ts(4,10): error TS2552: Cannot find name 'Produto'. Did you mean 'produto'?
src/cascata.ts(5,23): error TS2552: Cannot find name 'Produto'. Did you mean 'produto'?

Os três erros vêm do mesmo engano, e o TS2552 até sugere o nome parecido. Estratégia: corrija sempre o primeiro erro e compile de novo. Muitas vezes os outros somem junto. Aqui, trocar type produto por type Produto resolve tudo.

Missões

Missão: o objeto está com dois problemas (uma propriedade com tipo errado e uma faltando). O tsc mostra um de cada vez: corrija, compile de novo e leia o próximo erro, até o programa mostrar Ana tem 30 anos.

type Pessoa = { nome: string; idade: number; ativa: boolean };
const p: Pessoa = { nome: "Ana", idade: "30" };
console.log(`${p.nome} tem ${p.idade} anos`);

type Pessoa = { nome: string; idade: number; ativa: boolean };
const p: Pessoa = { nome: "Ana", idade: 30, ativa: true };
console.log(`${p.nome} tem ${p.idade} anos`);

Ana tem 30 anos

Missão: corrija os dois erros (TS2588 e TS2551) e mostre Contador: 2.00.

const contador = 1;
contador = contador + 1;
console.log("Contador: " + contador.tofixed(2));

let contador = 1;
contador = contador + 1;
console.log("Contador: " + contador.toFixed(2));

Contador: 2.00

Resumo

  • Toda mensagem diz arquivo(linha,coluna), o código TSxxxx e a frase.
  • Os campeões: TS2322, TS2345, TS2339, TS2304, TS2554.
  • TS1xxx costuma ser sintaxe: olhe a linha apontada e a anterior.
  • Muitos erros? Corrija o primeiro e compile de novo.
