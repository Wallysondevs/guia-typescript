Arrays e Tuplas

Um array é uma lista. Em TypeScript, a lista tem tipo: “lista de números”, “lista de textos”. Já a tupla é uma lista de tamanho fixo em que cada posição tem o seu tipo, como um par [nome, idade].

Você vai aprender
  • As duas formas de escrever um array: number[] e Array<number>.
  • Por que lista[0] pode ser undefined no nosso projeto.
  • Arrays que não podem mudar: readonly string[].
  • Tuplas: [string, number], com nomes e desestruturação.

1. Array de um tipo só

const notas: number[] = [7.5, 8, 9.5];
const nomes: Array<string> = ["Ana", "Duda", "Caio"];

notas.push(10);
console.log(notas);
console.log(nomes.join(", "));
console.log(notas.length);
$ npx tsc && node dist/arrays.js
[ 7.5, 8, 9.5, 10 ]
Ana, Duda, Caio
4

number[] e Array<number> são a mesma coisa. A primeira forma é a mais usada; a segunda aparece de novo na aula Generics.

O compilador não deixa entrar um item do tipo errado:

const notas: number[] = [7.5, 8];
notas.push("dez");
$ npx tsc
src/push.ts(2,12): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.

2. Lendo um item: talvez ele não exista

O nosso tsconfig.json (criado pelo --init) liga a opção noUncheckedIndexedAccess. Com ela, ler lista[0] devolve “número ou undefined”, porque a lista pode estar vazia:

const notas: number[] = [7.5, 8, 9.5];
const primeira = notas[0];
console.log(primeira.toFixed(1));
$ npx tsc
src/indice.ts(3,13): error TS18048: 'primeira' is possibly 'undefined'.

O TS18048 diz: “primeira pode ser undefined”. Confira antes de usar, com um if (o assunto da aula Narrowing):

const notas: number[] = [7.5, 8, 9.5];
const primeira = notas[0];
if (primeira !== undefined) {
  console.log(primeira.toFixed(1));
}
for (const n of notas) {
  console.log(n * 2);
}
$ npx tsc && node dist/indice.js
7.5
15
16
19

No for...of não é preciso conferir: cada n é um item que existe de verdade.

3. Arrays somente leitura

const dias: readonly string[] = ["seg", "ter", "qua"];
console.log(dias[1]);
dias.push("qui");
$ npx tsc
src/readonly.ts(3,6): error TS2339: Property 'push' does not exist on type 'readonly string[]'.

Com readonly, os métodos que mudam a lista (push, pop, sort…) nem existem no tipo. Bom para listas que ninguém deveria mexer.

4. Tuplas: cada posição com o seu tipo

const pessoa: [string, number] = ["Ana", 30];
const [nome, idade] = pessoa;
console.log(nome.toUpperCase(), idade + 1);

const ponto: [x: number, y: number] = [10, 20];
console.log(`x=${ponto[0]} y=${ponto[1]}`);
$ npx tsc && node dist/tuplas.js
ANA 31
x=10 y=20

Na tupla, o compilador sabe que a posição 0 é string e a 1 é number, e sabe que elas existem (sem o undefined do item 2). Os nomes em [x: number, y: number] são só documentação.

Quando dá errado

Tupla na ordem trocada ou com tamanho errado 
const a: [string, number] = [30, "Ana"];
const b: [string, number] = ["Ana", 30, true];
const c: [string, number] = ["Ana", 30];
console.log(c[2]);
$ npx tsc
src/tupla-errada.ts(1,30): error TS2322: Type 'number' is not assignable to type 'string'.
src/tupla-errada.ts(1,34): error TS2322: Type 'string' is not assignable to type 'number'.
src/tupla-errada.ts(2,7): error TS2322: Type '[string, number, boolean]' is not assignable to type '[string, number]'.
  Source has 3 element(s) but target allows only 2.
src/tupla-errada.ts(4,15): error TS2493: Tuple type '[string, number]' of length '2' has no element at index '2'.

Ordem trocada dá TS2322 em cada posição; um item a mais também; e ler uma posição que a tupla não tem dá TS2493.

Array vazio sem tipo 
const compras = [];
compras.push("pão");
compras.push(3);
const primeiro: boolean = compras;
$ npx tsc
src/vazio.ts(4,7): error TS2322: Type '(string | number)[]' is not assignable to type 'boolean'.

Sem tipo, o array vazio aceita tudo e vira (string | number)[]. Prefira dizer o tipo: const compras: string[] = [];.

Missões

Missão: crie const precos: number[] = [12.5, 20, 10];, some os itens com um for...of e mostre Total: 42.5.

const precos = [12.5, 20, 10];
let total = 0;
console.log("Total: " + total);

const precos: number[] = [12.5, 20, 10];
let total = 0;
for (const p of precos) {
  total += p;
}
console.log("Total: " + total);

Total: 42.5

Missão: guarde ["Caio", 25] numa tupla do tipo [string, number], desestruture em duas constantes e mostre Caio tem 25 anos.

const pessoa = ["Caio", 25];
console.log(pessoa);

const pessoa: [string, number] = ["Caio", 25];
const [nome, idade] = pessoa;
console.log(`${nome} tem ${idade} anos`);

Caio tem 25 anos

Missão: crie const cores: readonly string[] = ["azul", "verde"]; e tente cores.push("rosa"). Cole o erro.

const cores: string[] = ["azul", "verde"];
cores.push("rosa");
console.log(cores);

const cores: readonly string[] = ["azul", "verde"];
cores.push("rosa");

src/missao.ts(2,7): error TS2339: Property 'push' does not exist on type 'readonly string[]'.

Resumo

  • number[] = Array<number>: lista de um tipo só.
  • Com noUncheckedIndexedAccess, lista[i] pode ser undefined: confira antes ou use for...of.
  • readonly tira os métodos que mudam a lista.
  • Tupla: tamanho fixo, um tipo por posição, ótima com desestruturação.
