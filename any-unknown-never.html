any, unknown e never

Três tipos fogem da regra. O any é “qualquer coisa, e não me confira”. O unknown é “qualquer coisa, mas confira antes de usar”. O never é “isto nunca acontece”. Saber escolher entre eles separa o código seguro do código que só parece seguro.

Você vai aprender
  • Por que o any é perigoso, com um erro que só aparece ao rodar.
  • A usar unknown para dados de fora, conferindo com typeof.
  • O que é never e onde ele aparece.
  • De bônus: void, o retorno de funções que não devolvem nada.

1. any: o TypeScript desligado

let valor: any = "texto";
valor = 42;
valor = true;

console.log(valor.toUpperCase());
$ npx tsc && node dist/any.js
file:///home/ana/projeto/dist/any.js:4
console.log(valor.toUpperCase());
                  ^

TypeError: valor.toUpperCase is not a function
    at file:///home/ana/projeto/dist/any.js:4:19
    at ModuleJob.run (node:internal/modules/esm/module_job:561:25)
    at async node:internal/modules/esm/loader:647:26
    at async asyncRunEntryPointWithESMLoader (node:internal/modules/run_main:101:5)

Node.js v24.22.1

O tsc ficou calado: com any, ele aceita qualquer operação. O erro só apareceu rodando: valor era true, e booleano não tem toUpperCase. Foi exatamente o tipo de problema que o TypeScript existe para evitar.

Regra

Evite any. Ele “contamina”: o que sai de um any também é any, e a conferência some por onde ele passa.

2. unknown: qualquer coisa, mas com cuidado

O unknown também aceita qualquer valor, mas não deixa você usar o valor sem conferir o que ele é:

let valor: unknown = "texto";
console.log(valor.toUpperCase());
$ npx tsc
src/unknown.ts(2,13): error TS18046: 'valor' is of type 'unknown'.

Confira com typeof. Dentro do if, o compilador sabe que é string:

function descrever(valor: unknown) {
  if (typeof valor === "string") {
    return "texto: " + valor.toUpperCase();
  }
  if (typeof valor === "number") {
    return "número: " + valor.toFixed(2);
  }
  return "outra coisa";
}

console.log(descrever("oi"));
console.log(descrever(3.14159));
console.log(descrever(true));
$ npx tsc && node dist/unknown.js
texto: OI
número: 3.14
outra coisa

Use unknown para dados que vêm de fora e você ainda não conferiu: o texto de um arquivo JSON, a resposta de uma API, o catch de um erro.

const dados: unknown = JSON.parse('{"nome": "Ana"}');
console.log(typeof dados);
console.log(dados.nome);
$ npx tsc
src/json.ts(3,13): error TS18046: 'dados' is of type 'unknown'.

3. never: o que nunca acontece

Uma função que sempre lança um erro nunca chega ao fim; o tipo do retorno dela é never:

function falhar(mensagem: string): never {
  throw new Error(mensagem);
}

function dividir(a: number, b: number): number {
  if (b === 0) {
    falhar("divisão por zero");
  }
  return a / b;
}

console.log(dividir(10, 4));
try {
  dividir(1, 0);
} catch (e) {
  console.log("Pegou:", (e as Error).message);
}
$ npx tsc && node dist/never.js
2.5
Pegou: divisão por zero

O never também aparece quando o compilador conclui que um caso é impossível. Na aula Discriminated Unions você usa isso para ter certeza de que tratou todos os casos. (O (e as Error) é uma asserção, assunto da aula Asserções de Tipo.)

4. Bônus: void

Uma função que termina mas não devolve nada tem retorno void:

function avisar(msg: string): void {
  console.log("Aviso: " + msg);
}
avisar("salvo");

function errado(): void {
  return 10;
}
$ npx tsc
src/void.ts(7,3): error TS2322: Type 'number' is not assignable to type 'void'.

Quando dá errado

Atribuir unknown a um tipo concreto 
const entrada: unknown = "42";
const numero: number = entrada;
$ npx tsc
src/atribuir.ts(2,7): error TS2322: Type 'unknown' is not assignable to type 'number'.

O unknown só pode ir para outro lugar depois de conferido.

Nada pode ser atribuído a never 
let impossivel: never = 1;
$ npx tsc
src/never-erro.ts(1,5): error TS2322: Type '1' is not assignable to type 'never'.

Missões

Missão: escreva function dobrar(x: unknown) que, se x for number (confira com typeof), mostra dobro: seguido do dobro; senão mostra não é número. Chame com 7 e com "7".

function dobrar(x: any) {
  console.log("dobro: " + x * 2);
}
dobrar(7);
dobrar("7");

function dobrar(x: unknown) {
  if (typeof x === "number") {
    console.log("dobro: " + x * 2);
  } else {
    console.log("não é número");
  }
}
dobrar(7);
dobrar("7");

dobro: 14
não é número

Missão: declare let msg: unknown = "oi"; e tente usar msg.toUpperCase() sem conferir. Cole o erro (o código dele começa com TS18046).

let msg: any = "oi";
console.log(msg.toUpperCase());

let msg: unknown = "oi";
console.log(msg.toUpperCase());

src/missao.ts(2,13): error TS18046: 'msg' is of type 'unknown'.

Resumo

  • any desliga a conferência: o erro só aparece rodando. Evite.
  • unknown aceita tudo, mas exige conferir (typeof) antes de usar.
  • never é o impossível: o retorno de quem sempre lança erro.
  • void é o retorno de quem não devolve nada.
