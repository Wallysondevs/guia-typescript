Arquivos de declaração (.d.ts)

Um arquivo .d.ts só tem tipos, sem código que roda. Ele descreve “o que existe e com que forma” para o compilador. É assim que pacotes em JavaScript ganham tipos, e é o que o tsc gera para o seu próprio código quando a opção declaration está ligada.

Você vai aprender
  • Ler o .d.ts que o tsc gera.
  • Escrever um .d.ts para um arquivo JavaScript.
  • declare function, declare const e declare global.
  • declare module como saída de emergência.

1. O .d.ts que o tsc gera

O nosso tsconfig.json tem "declaration": true. Compile um arquivo e veja o que aparece em dist/:

export type Operacao = "soma" | "produto";

export function calcular(op: Operacao, a: number, b: number): number {
  const resultado = op === "soma" ? a + b : a * b;
  return resultado;
}

export const VERSAO = "1.0";
$ npx tsc
$ ls dist
calc.d.ts
calc.d.ts.map
calc.js
calc.js.map
export type Operacao = "soma" | "produto";
export declare function calcular(op: Operacao, a: number, b: number): number;
export declare const VERSAO = "1.0";
//# sourceMappingURL=calc.d.ts.map

Sumiu todo o corpo da função: ficou só a “capa” (nomes, parâmetros e retornos). declare quer dizer “isto existe em algum lugar; confie”. Quem publica uma biblioteca em TypeScript entrega os .js (para rodar) e os .d.ts (para os tipos).

2. Tipando um arquivo JavaScript

Imagine um arquivo JavaScript antigo, fora da pasta src, que você não quer (ou não pode) reescrever:

export function cmParaPol(cm) {
  return cm / 2.54;
}
export const UNIDADES = ["cm", "pol"];
import { cmParaPol } from "../lib/medidas.js";
console.log(cmParaPol(254).toFixed(1));
$ npx tsc
src/main.ts(1,27): error TS7016: Could not find a declaration file for module '../lib/medidas.js'. '/home/ana/projeto/lib/medidas.js' implicitly has an 'any' type.

Crie, ao lado do .js e com o mesmo nome, o arquivo de declaração:

export declare function cmParaPol(cm: number): number;
export declare const UNIDADES: string[];
$ npx tsc && node dist/main.js
100.0

O TypeScript achou lib/medidas.d.ts para o import de ../lib/medidas.js. E agora os usos errados são pegos:

import { cmParaPol, UNIDADES } from "../lib/medidas.js";
console.log(cmParaPol("254"));
UNIDADES.push(3);
$ npx tsc
src/main.ts(2,23): error TS2345: Argument of type 'string' is not assignable to parameter of type 'number'.
src/main.ts(3,15): error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.
O .d.ts não confere o .js

O compilador confia no que o .d.ts diz. Se a declaração mentir (dizer que devolve string quando devolve número), o erro só aparece rodando. Escreva com cuidado.

3. declare global: variáveis globais

Às vezes um valor global é criado por outra parte do sistema (um script, uma configuração). Para o TypeScript aceitar, declare:

declare global {
  var configuracao: { modo: "dev" | "prod"; versao: number };
}

globalThis.configuracao = { modo: "dev", versao: 3 };
console.log(configuracao.modo, configuracao.versao);

configuracao.modo = "teste";
$ npx tsc
src/global.ts(8,1): error TS2322: Type '"teste"' is not assignable to type '"dev" | "prod"'.

O declare global { var … } acrescenta a variável ao escopo global; daí em diante ela é conferida como qualquer outra (por isso "teste" foi recusado). Dentro de declare global use var, não let/const.

4. declare module: o atalho para pacotes sem tipos

Quando um pacote não tem tipos nem @types, o TS7016 sugere declare module 'x';. Veja o efeito com um módulo inventado:

declare module "pacote-antigo";

declare module "pacote-pequeno" {
  export function saudar(nome: string): string;
}
import qualquer from "pacote-antigo";
import { saudar } from "pacote-pequeno";

qualquer.isso.nao.existe();
saudar(42);
$ npx tsc
src/uso.ts(5,8): error TS2345: Argument of type 'number' is not assignable to parameter of type 'string'.

O "pacote-antigo", declarado sem corpo, virou any: nada é conferido (a linha absurda passou). O "pacote-pequeno", com corpo, é conferido normalmente. Prefira sempre declarar o que você usa.

Quando dá errado

Colocar código num .d.ts 
export function dobro(n: number): number {
  return n * 2;
}
$ npx tsc

Nenhum erro?! É o "skipLibCheck": true do tsconfig.json: para compilar mais rápido, ele pula a conferência de todos os .d.ts, inclusive os seus. Para conferir os seus de vez em quando, desligue só nesta execução:

$ npx tsc --skipLibCheck false
src/errado.d.ts(1,42): error TS1183: An implementation cannot be declared in ambient contexts.

Em .d.ts não há implementação: escreva só a assinatura, terminada em ;.

Missões

Missão: crie lib/frete.js e src/main.ts abaixo. Depois escreva lib/frete.d.ts declarando calcularFrete(pesoKg: number, expresso: boolean): number. Rode com npx tsc && node dist/main.js. Saída esperada: Frete: R$ 35.00.

Antes, crie também o arquivo lib/frete.js:

export function calcularFrete(pesoKg, expresso) {
  return pesoKg * 5 + (expresso ? 20 : 0);
}

Antes, crie também o arquivo src/main.ts:

import { calcularFrete } from "../lib/frete.js";
const valor: number = calcularFrete(3, true);
console.log("Frete: R$ " + valor.toFixed(2));
// escreva aqui a declaração de calcularFrete

export declare function calcularFrete(pesoKg: number, expresso: boolean): number;

Frete: R$ 35.00

Missão: declare a variável global usuarioAtual (com declare global { var usuarioAtual: string }) para o código compilar e mostrar Logado: ana.

globalThis.usuarioAtual = "ana";
console.log("Logado: " + usuarioAtual);

declare global {
  var usuarioAtual: string;
}
globalThis.usuarioAtual = "ana";

Logado: ana

Resumo

  • .d.ts descreve tipos, sem código que roda.
  • Com declaration, o tsc gera .d.ts do seu código.
  • Um x.d.ts ao lado de x.js dá tipos ao JavaScript.
  • declare global para globais; declare module para pacotes.
