Interfaces

Uma interface é outra forma de descrever a forma de um objeto, parecida com o type da aula anterior. Ela é muito usada em bibliotecas e em código orientado a objetos, e tem dois truques próprios: estender outra interface com extends e juntar declarações com o mesmo nome.

Você vai aprender
  • A declarar uma interface com campos e métodos.
  • A criar uma interface a partir de outra com extends.
  • A fusão de declarações (duas interfaces com o mesmo nome viram uma).
  • Quando usar interface e quando usar type.

1. Declarando uma interface

interface Aluno {
  nome: string;
  notas: number[];
  turma?: string;
  media(): number;
}

const ana: Aluno = {
  nome: "Ana",
  notas: [8, 9, 10],
  media() {
    return this.notas.reduce((a, b) => a + b, 0) / this.notas.length;
  },
};

console.log(`${ana.nome}: média ${ana.media()}`);
console.log(ana.turma ?? "sem turma");
$ npx tsc && node dist/interface.js
Ana: média 9
sem turma

Repare que não há = depois do nome (diferente do type). O media(): number descreve um método: uma função dentro do objeto.

2. Estendendo com extends

interface Pessoa {
  nome: string;
  idade: number;
}

interface Funcionario extends Pessoa {
  cargo: string;
  salario: number;
}

const duda: Funcionario = { nome: "Duda", idade: 28, cargo: "Dev", salario: 7000 };
console.log(`${duda.nome}, ${duda.idade} anos, ${duda.cargo}`);

function apresentar(p: Pessoa) {
  console.log("Olá, " + p.nome);
}
apresentar(duda);
$ npx tsc && node dist/extends.js
Duda, 28 anos, Dev
Olá, Duda

Um Funcionario tem tudo de Pessoa e mais. Por isso ele pode ser passado onde se espera uma Pessoa.

3. A forma é o que importa

O TypeScript compara formas, não nomes. Um objeto que tem os campos certos serve, mesmo que nunca tenha “dito” que é daquela interface:

interface ComNome {
  nome: string;
}

function cumprimentar(x: ComNome) {
  console.log("Oi, " + x.nome);
}

const cachorro = { nome: "Rex", raca: "vira-lata" };
cumprimentar(cachorro);
cumprimentar({ nome: "Caio" });
$ npx tsc && node dist/forma.js
Oi, Rex
Oi, Caio

Isso se chama tipagem estrutural. O cachorro tem um campo a mais (raca), e tudo bem: o erro de campo sobrando (TS2353) só acontece quando o objeto é escrito direto no lugar onde o tipo é exigido.

4. Fusão de declarações

interface Config {
  tema: string;
}
interface Config {
  idioma: string;
}

const c: Config = { tema: "escuro", idioma: "pt-BR" };
console.log(c);
$ npx tsc && node dist/fusao.js
{ tema: 'escuro', idioma: 'pt-BR' }

Duas interfaces com o mesmo nome viram uma só. Com type isso é proibido:

type Config = { tema: string };
type Config = { idioma: string };
$ npx tsc
src/fusao-type.ts(1,6): error TS2300: Duplicate identifier 'Config'.
src/fusao-type.ts(2,6): error TS2300: Duplicate identifier 'Config'.

A fusão é útil para acrescentar campos a tipos de bibliotecas (aula Arquivos de Declaração).

Regra prática: use interface para formas de objetos e type para o resto (unions, funções, tuplas). Os dois funcionam; o importante é ser consistente no projeto.

Quando dá errado

Esquecer um método da interface 
interface Animal {
  nome: string;
  falar(): string;
}
const gato: Animal = { nome: "Mimi" };
$ npx tsc
src/metodo.ts(5,7): error TS2741: Property 'falar' is missing in type '{ nome: string; }' but required in type 'Animal'.

Missões

Missão: crie a interface Livro com titulo: string e autor: string, um livro e mostre "Vidas Secas", de Graciliano Ramos (com as aspas).

const livro = { titulo: "Vidas Secas", autor: "Graciliano Ramos" };

interface Livro {
  titulo: string;
  autor: string;
}
const livro: Livro = { titulo: "Vidas Secas", autor: "Graciliano Ramos" };
console.log(`"${livro.titulo}", de ${livro.autor}`);

"Vidas Secas", de Graciliano Ramos

Missão: crie interface Ave extends Animal com o campo velocidade: number, uma ave { nome: "Piu", velocidade: 30 } e mostre Piu voa a 30 km/h.

interface Animal {
  nome: string;
}

interface Animal {
  nome: string;
}
interface Ave extends Animal {
  velocidade: number;
}
const ave: Ave = { nome: "Piu", velocidade: 30 };
console.log(`${ave.nome} voa a ${ave.velocidade} km/h`);

Piu voa a 30 km/h

Resumo

  • interface Nome { … } descreve a forma de um objeto, com campos e métodos.
  • extends cria uma interface a partir de outra.
  • O TypeScript compara formas (tipagem estrutural).
  • Interfaces com o mesmo nome se juntam; type duplicado é erro.
