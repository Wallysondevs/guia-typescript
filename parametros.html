Parâmetros Opcionais e Padrão

Nem todo argumento precisa ser obrigatório. Um parâmetro pode ser opcional (?), ter um valor padrão (= valor) ou juntar “todos os que vierem” num array (...resto). O TypeScript entende os três e confere o tipo de cada um.

Você vai aprender
  • Parâmetros opcionais com ? e por que eles podem ser undefined.
  • Valores padrão, que dispensam a anotação.
  • Parâmetros rest: ...numeros: number[].
  • A regra da ordem: obrigatórios antes dos opcionais.

1. Opcional com ?

function apresentar(nome: string, cidade?: string): string {
  if (cidade) {
    return `${nome}, de ${cidade}`;
  }
  return nome;
}

console.log(apresentar("Ana", "Recife"));
console.log(apresentar("Duda"));
$ npx tsc && node dist/opcional.js
Ana, de Recife
Duda

Dentro da função, cidade é string | undefined: pode ter vindo ou não. Por isso o if. Sem ele:

function apresentar(nome: string, cidade?: string): string {
  return nome + " de " + cidade.toUpperCase();
}
$ npx tsc
src/opcional-erro.ts(2,26): error TS18048: 'cidade' is possibly 'undefined'.

2. Valor padrão

Com = valor, se o argumento não vier, entra o padrão. O tipo é inferido pelo valor:

function preco(valor: number, desconto = 0.1): string {
  const final = valor * (1 - desconto);
  return final.toFixed(2);
}

console.log(preco(100));
console.log(preco(100, 0.25));
console.log(preco(100, 0));
$ npx tsc && node dist/padrao.js
90.00
75.00
100.00

O desconto ficou number sem anotação. E, diferente do opcional, dentro da função ele nunca é undefined: o padrão garante um valor.

3. Rest: quantos vierem

function somarTodos(...numeros: number[]): number {
  let total = 0;
  for (const n of numeros) total += n;
  return total;
}

console.log(somarTodos());
console.log(somarTodos(5));
console.log(somarTodos(1, 2, 3, 4));

const lista = [10, 20, 30];
console.log(somarTodos(...lista));
$ npx tsc && node dist/rest.js
0
5
10
60

O ...numeros junta todos os argumentos num array, por isso o tipo é number[]. E o ...lista na chamada faz o contrário: espalha o array em argumentos.

4. A ordem importa

Parâmetros opcionais vêm depois dos obrigatórios, e o rest vem por último:

function errada(cidade?: string, nome: string) {
  return nome;
}
$ npx tsc
src/ordem.ts(1,34): error TS1016: A required parameter cannot follow an optional parameter.

Quando dá errado

Padrão do tipo errado 
function repetir(texto: string, vezes: number = "2") {
  return texto.repeat(vezes);
}
$ npx tsc
src/padrao-erro.ts(1,33): error TS2322: Type 'string' is not assignable to type 'number'.
Rest com item de outro tipo 
function somarTodos(...numeros: number[]): number {
  return numeros.reduce((a, b) => a + b, 0);

$ npx tsc

Missões

Missão: escreva function ola(nome?: string) que mostra Olá, Ana! quando recebe "Ana" e Olá, visitante! quando não recebe nada. Chame das duas formas. Dica: nome ?? "visitante" usa o texto da direita quando nome é undefined (mais na aula null, undefined e ?.).

function ola(nome: string) {
  console.log(`Olá, ${nome}!`);
}
ola("Ana");

function ola(nome?: string) {
  console.log(`Olá, ${nome ?? "visitante"}!`);
}
ola("Ana");
ola();

Olá, Ana!
Olá, visitante!

Missão: escreva function maior(...valores: number[]): number que devolve o maior valor (dica: Math.max(...valores)) e mostre Maior: 42 para maior(3, 42, 7, 15).

function maior(valores: number[]): number {
  return 0;
}

function maior(...valores: number[]): number {
  return Math.max(...valores);
}
console.log("Maior: " + maior(3, 42, 7, 15));

Maior: 42

Missão: dê ao parâmetro vezes o valor padrão 3 e mostre eco("ei"), que deve imprimir ei ei ei.

function eco(texto: string, vezes: number) {
  return Array(vezes).fill(texto).join(" ");
}
console.log(eco("ei"));

function eco(texto: string, vezes = 3) {
  return Array(vezes).fill(texto).join(" ");
}
console.log(eco("ei"));

ei ei ei

Resumo

  • ? torna o parâmetro opcional; dentro, ele pode ser undefined.
  • = valor dá um padrão e o tipo é inferido.
  • ...resto: T[] junta os argumentos num array.
  • Ordem: obrigatórios, depois opcionais/padrão, e o rest por último.
