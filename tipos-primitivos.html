Tipos Primitivos

Os tipos primitivos são os tijolos de tudo em TypeScript: texto, números, verdadeiro/falso e os “vazios” null e undefined. Nesta aula você aprende a escrever o tipo de uma variável com : tipo e vê o que o compilador responde quando o valor não combina com o tipo.

Você vai aprender
  • Os primitivos string, number, boolean, bigint, null e undefined.
  • A anotação de tipo: let nome: string = "Ana";.
  • A ler o erro TS2322, o mais comum de todos.
  • Por que se escreve string com letra minúscula (e não String).

Todos os exemplos foram rodados de verdade no projeto da aula Instalando o TypeScript: o arquivo fica em src/, o npx tsc compila e o node roda o JavaScript gerado em dist/.

A ideia: etiquetas nas caixas

Pense numa variável como uma caixa. No JavaScript a caixa aceita qualquer coisa. No TypeScript você pode colar uma etiqueta na caixa dizendo o que vai dentro: “só texto”, “só número”. Se alguém tentar guardar outra coisa, o compilador reclama antes de o programa rodar.

let
cria a variável (pode mudar depois; const não muda)
idade
o nome da variável
: number
a anotação de tipo: a etiqueta da caixa
= 30;
o valor guardado, que precisa combinar com a etiqueta

1. Os três do dia a dia: string, number e boolean

Crie o arquivo src/primitivos.ts:

let nome: string = "Ana";
let idade: number = 30;
let altura: number = 1.68;
let estudante: boolean = true;

console.log(nome, idade, altura, estudante);
console.log(typeof nome, typeof idade, typeof estudante);

Compile e rode:

$ npx tsc
$ node dist/primitivos.js
Ana 30 1.68 true
string number boolean

O tsc não escreveu nada: em TypeScript, silêncio quer dizer sucesso. Repare que number serve para inteiros (30) e para números com vírgula (1.68, escrito com ponto). E o typeof, que roda no JavaScript, mostra os mesmos nomes dos tipos.

Se você abrir o arquivo gerado, verá que as anotações sumiram. Os tipos existem só para o compilador:

let nome = "Ana";
let idade = 30;
let altura = 1.68;
let estudante = true;
console.log(nome, idade, altura, estudante);
console.log(typeof nome, typeof idade, typeof estudante);
export {};
//# sourceMappingURL=primitivos.js.map

2. bigint, null e undefined

Para inteiros gigantes existe o bigint (o número termina com n). Já null e undefined são tipos que só aceitam a si mesmos: null é “vazio de propósito” e undefined é “ainda não tem valor”.

let populacao: bigint = 8_100_000_000n;
let apelido: null = null;
let telefone: undefined = undefined;

console.log(populacao * 2n);
console.log(apelido, telefone);
$ npx tsc
$ node dist/outros.js
16200000000n
null undefined
Dica

O _ em 8_100_000_000n é só um separador para facilitar a leitura. Ele vale também para number: 1_000_000.

3. Quando o valor não combina com a etiqueta

Agora o erro de propósito. Crie src/erro.ts:

let idade: number = 30;
idade = "trinta";

let ativo: boolean = "sim";
$ npx tsc
src/erro.ts(2,1): error TS2322: Type 'string' is not assignable to type 'number'.
src/erro.ts(4,5): error TS2322: Type 'string' is not assignable to type 'boolean'.

Leia a mensagem por partes: src/erro.ts(2,1) é o arquivo, a linha 2 e a coluna 1. Depois vem o código do erro, TS2322, e a frase em inglês: “o tipo string não pode ser atribuído ao tipo number”. O guia nunca traduz essas mensagens: você vai vê-las exatamente assim no seu terminal.

Atenção

Mesmo com erro, o tsc gerou o dist/erro.js. Ele avisa, mas não impede. Por isso, nas missões, usamos npx tsc && node …: o && só roda o node se o tsc terminar sem erro.

4. string, e não String

Existe também String (com maiúscula), mas ele é o tipo de um objeto embrulhando o texto. Use sempre os nomes em minúsculas: string, number, boolean. Os exercícios deste guia conferem maiúsculas e minúsculas, assim como o compilador.

Quando dá errado

Escrever o nome do tipo em português 
let preco: numero = 10;
console.log(preco);
$ npx tsc
src/tipo-errado.ts(1,12): error TS2552: Cannot find name 'numero'. Did you mean 'number'?

O TS2552 (“Cannot find name”) quer dizer que o compilador não conhece o nome numero. Ele até sugere o certo: Did you mean 'number'? Os tipos têm nome em inglês.

Usar uma variável antes de dar valor 
let cidade: string;
console.log(cidade.toUpperCase());
$ npx tsc
src/sem-valor.ts(2,13): error TS2454: Variable 'cidade' is used before being assigned.

Com o modo strict (ligado no projeto), o compilador percebe que cidade ainda não recebeu valor e avisa com TS2454.

Resumo

  • A anotação : tipo é a etiqueta da variável: let idade: number = 30;.
  • Os primitivos são string, number, boolean, bigint, null e undefined, sempre em minúsculas.
  • O erro TS2322 aparece quando o valor não combina com o tipo; o tsc avisa, mas gera o .js mesmo assim.
  • No JavaScript gerado, os tipos somem.
