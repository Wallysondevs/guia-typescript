A palavra infer

Os conditional types perguntam “T tem esta forma?”. Com infer, eles também capturam um pedaço dessa forma: “se T for uma lista de alguma coisa, me diga que coisa”. É o mecanismo por trás do ReturnType, do Parameters e do Awaited.

Você vai aprender
  • A sintaxe T extends Forma<infer X> ? X : ….
  • Extrair o item de uma lista e o valor de uma Promise.
  • Escrever o seu próprio ReturnType.
  • Usar Awaited, ReturnType e Parameters no dia a dia.

1. Capturando o item de uma lista

type ItemDe<T> = T extends (infer I)[] ? I : never;

const a: ItemDe<string[]> = "texto";
const b: ItemDe<number[]> = 42;
const c: ItemDe<boolean> = true;
console.log(a, b);
$ npx tsc
src/item.ts(5,7): error TS2322: Type 'true' is not assignable to type 'never'.
T extends (infer I)[]
“T é uma lista de algo? Chame esse algo de I”.
? I : never
se for, o resultado é o item; se não for (como boolean), never, que não aceita valor nenhum.

2. O valor de dentro de uma Promise

type Desembrulha<T> = T extends Promise<infer V> ? V : T;

async function buscarIdade(): Promise<number> {
  return 30;
}

const idade: Desembrulha<ReturnType<typeof buscarIdade>> = 30;
const nome: Desembrulha<string> = "Ana";
const pronto: Awaited<Promise<Promise<boolean>>> = true;
console.log(idade, nome, pronto);

const errado: Desembrulha<Promise<number>> = "trinta";
$ npx tsc
src/promessa.ts(12,7): error TS2322: Type 'string' is not assignable to type 'number'.

Awaited é a versão pronta (e mais completa) disso: ela desembrulha até Promises dentro de Promises.

3. O seu próprio ReturnType

O infer pode aparecer em qualquer lugar da forma, inclusive no retorno de uma função:

type Retorno<F> = F extends (...args: any[]) => infer R ? R : never;
type PrimeiroParam<F> = F extends (primeiro: infer P, ...resto: any[]) => any ? P : never;

function criarUsuario(nome: string, idade: number) {
  return { nome, idade, criadoEm: "2026-11-21" };
}

type Usuario = Retorno<typeof criarUsuario>;
type Nome = PrimeiroParam<typeof criarUsuario>;

const u: Usuario = criarUsuario("Ana", 30);
const n: Nome = "Caio";
console.log(u, n);

const faltando: Usuario = { nome: "Duda", idade: 25 };
$ npx tsc
src/retorno.ts(15,7): error TS2741: Property 'criadoEm' is missing in type '{ nome: string; idade: number; }' but required in type '{ nome: string; idade: number; criadoEm: string; }'.

O tipo Usuario nasceu da função: se a função mudar, o tipo muda junto. É a mesma ideia do ReturnType e do Parameters prontos.

4. Com os utilitários prontos

async function carregarConfig(caminho: string, tentativas: number) {
  return { caminho, tentativas, tema: "escuro" as const };
}

type Args = Parameters<typeof carregarConfig>;
type Config = Awaited<ReturnType<typeof carregarConfig>>;

const args: Args = ["/etc/app.json", 3];
const cfg: Config = await carregarConfig(...args);
console.log(cfg.tema, cfg.tentativas);

const argsErrados: Args = ["/etc/app.json"];
$ npx tsc
src/prontos.ts(12,7): error TS2322: Type '[string]' is not assignable to type '[caminho: string, tentativas: number]'.
  Source has 1 element(s) but target requires 2.

Quando dá errado

infer fora de um conditional type 
type Item = (infer I)[];
$ npx tsc
src/solto.ts(1,14): error TS1338: 'infer' declarations are only permitted in the 'extends' clause of a conditional type.

infer só existe na parte extends de um conditional type.

typeof esquecido 
function dobro(n: number) {
  return n * 2;
}
type R = ReturnType<dobro>;
$ npx tsc
src/sem-typeof.ts(4,21): error TS2749: 'dobro' refers to a value, but is being used as a type here. Did you mean 'typeof dobro'?

dobro é um valor (uma função); utilitários de tipo recebem tipos. Use ReturnType<typeof dobro>, como a própria mensagem sugere.

Missões

Missão: escreva PrimeiroDa<T> com infer, que extrai o tipo do primeiro item de uma tupla (T extends [infer P, ...any[]] ? P : never). Saída esperada: Ana tem 30 anos.

type PrimeiroDa<T> = unknown;
type Registro = [string, number];
const quem: PrimeiroDa<Registro> = "Ana";
console.log(quem.toString() + " tem 30 anos");

type PrimeiroDa<T> = T extends [infer P, ...any[]] ? P : never;
type Registro = [string, number];
const quem: PrimeiroDa<Registro> = "Ana";
console.log(quem.toString() + " tem 30 anos");

Ana tem 30 anos

Missão: sem reescrever o formato à mão, crie type Pedido = Awaited<ReturnType<typeof buscarPedido>> e use-o na função resumo. Saída esperada: Pedido 12: 3 itens.

async function buscarPedido() {
  return { id: 12, itens: ["a", "b", "c"] };
}
function resumo(p: any): string {
  return `Pedido ${p.id}: ${p.itens.length} itens`;
}
console.log(resumo(await buscarPedido()));

async function buscarPedido() {
  return { id: 12, itens: ["a", "b", "c"] };
}
type Pedido = Awaited<ReturnType<typeof buscarPedido>>;
function resumo(p: Pedido): string {
  return `Pedido ${p.id}: ${p.itens.length} itens`;
}
console.log(resumo(await buscarPedido()));

Pedido 12: 3 itens

Resumo

  • infer X captura um pedaço do tipo dentro de um extends.
  • Serve para pegar item de lista, valor de Promise, retorno e parâmetros de funções.
  • ReturnType, Parameters e Awaited são feitos com infer.
  • Para usar uma função como tipo, passe typeof funcao.
