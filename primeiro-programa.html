Primeiro Programa (tsc)

Com o projeto pronto, é hora do clássico “Olá, mundo”. Você vai fazer o ciclo completo do TypeScript: escrever em src/, compilar com npx tsc e rodar com node. E vai aprender a ler uma mensagem de erro de ponta a ponta.

Você vai aprender
  • O ciclo escrever → npx tsc → node dist/….
  • A juntar os dois passos com &&.
  • As partes de uma mensagem de erro: arquivo, linha, coluna, código e texto.
  • A deixar o compilador vigiando os arquivos com --watch.

1. Olá, mundo

Crie src/ola.ts:

const nome: string = "Ana";
const mensagem: string = `Olá, ${nome}! Bem-vinda ao TypeScript.`;

console.log(mensagem);
console.log("Hoje é dia de aprender tipos.");
$ npx tsc
$ node dist/ola.js
Olá, Ana! Bem-vinda ao TypeScript.
Hoje é dia de aprender tipos.

O `…${nome}…` é uma template string do JavaScript: o valor de nome entra no meio do texto. Tudo o que vale no JavaScript vale no TypeScript.

2. Os dois passos numa linha só

npx tsc
confere e compila o projeto
&&
“e, se deu certo, então…”
node dist/ola.js
roda o JavaScript gerado
$ npx tsc && node dist/ola.js
Olá, Ana! Bem-vinda ao TypeScript.
Hoje é dia de aprender tipos.

Se o tsc achar erro, o && impede o node de rodar. É exatamente o comando das missões.

3. Lendo uma mensagem de erro

Vamos errar de propósito, chamando um método que não existe e trocando o tipo de uma constante:

const nome: string = "Ana";
console.log(nome.toUppercase());

const ano: number = "2026";
console.log(ano);
$ npx tsc && node dist/ola.js
src/ola.ts(2,18): error TS2551: Property 'toUppercase' does not exist on type 'string'. Did you mean 'toUpperCase'?
src/ola.ts(4,7): error TS2322: Type 'string' is not assignable to type 'number'.
PedaçoO que quer dizer
src/ola.tso arquivo com problema
(2,18)linha 2, coluna 18 (onde começa o problema)
error TS2551o código do erro: dá para pesquisar por ele
Property 'toUppercase' does not exist…a explicação: a propriedade não existe; e a sugestão Did you mean 'toUpperCase'?

Repare que o node não rodou: os dois erros apareceram e o && parou tudo. Corrija o C maiúsculo e tire as aspas do 2026:

const nome: string = "Ana";
console.log(nome.toUpperCase());

const ano: number = 2026;
console.log(ano);
$ npx tsc && node dist/ola.js
ANA
2026

4. Deixar o compilador vigiando: --watch

Em vez de rodar npx tsc a cada mudança, você pode deixá-lo vigiando: npx tsc --watch compila de novo toda vez que você salva um arquivo. Ele fica rodando até você apertar Ctrl+C. Use um segundo terminal para o node.

Para só conferir os tipos, sem gerar nenhum arquivo, use --noEmit:

$ npx tsc --noEmit
$ ls
node_modules
package-lock.json
package.json
src
tsconfig.json

Nenhuma resposta (tudo certo) e nenhuma pasta dist criada.

Esquecer de fechar aspas 
console.log("Olá);
$ npx tsc
src/aspas.ts(1,19): error TS1002: Unterminated string literal.

Erros de sintaxe (código mal escrito) têm códigos baixos, como TS1002. Os de tipo ficam na casa dos TS2xxx.

Missões

Missão: guarde "Bia" numa const nome: string e mostre Olá, Bia! Seja bem-vinda. usando uma template string com ${nome}.

const nome = "Bia";
console.log("Olá, " + nome + "! Seja bem-vinda.");

const nome: string = "Bia";
console.log(`Olá, ${nome}! Seja bem-vinda.`);

Olá, Bia! Seja bem-vinda.

Missão: o código tem um erro de digitação no nome do método. Rode, leia a sugestão do compilador, corrija e mostre TYPESCRIPT.

const linguagem: string = "typescript";
console.log(linguagem.toUppercase());

const linguagem: string = "typescript";
console.log(linguagem.toUpperCase());

TYPESCRIPT

Resumo

  • Ciclo: escrever em src/, npx tsc, node dist/…; ou tudo junto com &&.
  • Mensagem de erro: arquivo(linha,coluna): error TScódigo: explicação.
  • --watch recompila sozinho; --noEmit só confere.
