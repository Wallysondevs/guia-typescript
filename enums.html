Enums

Um enum agrupa constantes com nome: os dias da semana, os status de um pedido, as direções. Ele é um dos poucos recursos do TypeScript que existe também no JavaScript gerado. Nesta aula você vê os dois tipos de enum, o código que o tsc cria para eles e a alternativa que muita gente prefere hoje.

Você vai aprender
  • Enums numéricos e enums de texto.
  • O JavaScript que o tsc gera para um enum.
  • O const enum.
  • A alternativa sem enum: union de literais e objeto as const.

1. Enum numérico

enum Direcao {
  Cima,
  Baixo,
  Esquerda,
  Direita,
}

let d: Direcao = Direcao.Esquerda;
console.log(d);
console.log(Direcao[d]);
console.log(Direcao.Cima, Direcao.Direita);
$ npx tsc && node dist/enum.js
2
Esquerda
0 3

Sem valores escritos, o primeiro vale 0 e os outros seguem: 1, 2, 3. E o enum numérico funciona nos dois sentidos: Direcao[2] devolve o nome "Esquerda". Veja o porquê no JavaScript gerado:

var Direcao;
(function (Direcao) {
    Direcao[Direcao["Cima"] = 0] = "Cima";
    Direcao[Direcao["Baixo"] = 1] = "Baixo";
    Direcao[Direcao["Esquerda"] = 2] = "Esquerda";
    Direcao[Direcao["Direita"] = 3] = "Direita";
})(Direcao || (Direcao = {}));
let d = Direcao.Esquerda;
console.log(d);
console.log(Direcao[d]);
console.log(Direcao.Cima, Direcao.Direita);
export {};
//# sourceMappingURL=enum.js.map

O tsc criou um objeto de verdade, com as chaves nos dois sentidos. Por isso o enum é diferente dos outros tipos: ele não some.

2. Enum de texto

enum Status {
  Pendente = "PENDENTE",
  Pago = "PAGO",
  Enviado = "ENVIADO",
}

function descrever(s: Status) {
  if (s === Status.Pago) return "Pagamento confirmado";
  return "Situação: " + s;
}

console.log(descrever(Status.Pago));
console.log(descrever(Status.Enviado));
$ npx tsc && node dist/status.js
Pagamento confirmado
Situação: ENVIADO

Com texto, o valor que aparece no log é legível (ENVIADO em vez de 2). Mas o enum de texto é rigoroso: um texto solto não é aceito no lugar dele:

enum Status {
  Pendente = "PENDENTE",
  Pago = "PAGO",
}
function descrever(s: Status) {
  return s;
}
descrever("PAGO");
$ npx tsc
src/status-erro.ts(8,11): error TS2345: Argument of type '"PAGO"' is not assignable to parameter of type 'Status'.

3. const enum

Um const enum foi pensado para não gerar objeto: o tsc trocaria cada uso pelo valor direto. Veja o que acontece no nosso projeto:

const enum Nivel {
  Baixo = 1,
  Medio = 2,
  Alto = 3,
}
const n = Nivel.Alto;
console.log(n);
$ npx tsc && node dist/const-enum.js
3
var Nivel;
(function (Nivel) {
    Nivel[Nivel["Baixo"] = 1] = "Baixo";
    Nivel[Nivel["Medio"] = 2] = "Medio";
    Nivel[Nivel["Alto"] = 3] = "Alto";
})(Nivel || (Nivel = {}));
const n = Nivel.Alto;
console.log(n);
export {};
//# sourceMappingURL=const-enum.js.map

Surpresa: o objeto foi gerado do mesmo jeito. O motivo é a opção isolatedModules (ligada pelo tsc --init, e implícita no verbatimModuleSyntax): ela exige que cada arquivo possa ser convertido sozinho, sem olhar os outros, e aí o tsc preserva o enum. Desligando as duas opções só nesta compilação, o comportamento “clássico” aparece:

$ npx tsc --isolatedModules false --verbatimModuleSyntax false
const n = 3 /* Nivel.Alto */;
console.log(n);
export {};
//# sourceMappingURL=const-enum.js.map

Agora o enum sumiu e sobrou o número 3 com o comentário /* Nivel.Alto */. Como os projetos modernos deixam isolatedModules ligado, o const enum perdeu boa parte da graça; a alternativa abaixo é mais comum.

4. A alternativa sem enum

Muita gente prefere uma union de literais (aula Union e Literal Types): ela some no JavaScript, aceita o texto direto e o Node consegue rodar sem compilar. Quando é preciso também um objeto com os valores, usa-se as const:

type Status = "PENDENTE" | "PAGO" | "ENVIADO";

function descrever(s: Status) {
  return "Situação: " + s;
}
console.log(descrever("PAGO"));

const Cor = {
  Vermelho: "#f00",
  Verde: "#0f0",
} as const;
type Cor = (typeof Cor)[keyof typeof Cor];

const fundo: Cor = Cor.Verde;
console.log(fundo, Object.keys(Cor));
$ npx tsc && node dist/alternativa.js
Situação: PAGO
#0f0 [ 'Vermelho', 'Verde' ]

O as const torna o objeto somente leitura e com tipos literais. A linha type Cor = … usa typeof e keyof, que você vê na aula keyof e typeof.

Quando dá errado

Um nome que o enum não tem 
enum Direcao { Cima, Baixo }
console.log(Direcao.Lado);
$ npx tsc
src/nome-errado.ts(2,21): error TS2339: Property 'Lado' does not exist on type 'typeof Direcao'.
Mudar o valor de um membro 
enum Direcao { Cima, Baixo }
Direcao.Cima = 5;
$ npx tsc
src/mudar.ts(2,9): error TS2540: Cannot assign to 'Cima' because it is a read-only property.

Os membros do enum são somente leitura.

Missões

Missão: crie enum DiaUtil { Segunda, Terca, Quarta, Quinta, Sexta } e mostre Quarta é o dia 2 usando DiaUtil.Quarta (o número) e DiaUtil[DiaUtil.Quarta] (o nome).

const dias = ["Segunda", "Terca", "Quarta", "Quinta", "Sexta"];
console.log(dias[2]);

enum DiaUtil { Segunda, Terca, Quarta, Quinta, Sexta }
console.log(`${DiaUtil[DiaUtil.Quarta]} é o dia ${DiaUtil.Quarta}`);

Quarta é o dia 2

Missão: crie o enum de texto Moeda com Real = "BRL" e Dolar = "USD", e use em preco(valor: number, m: Moeda) para mostrar Preço: 10 BRL e Preço: 2 USD.

function preco(valor: number, m: string) {
  console.log(`Preço: ${valor} ${m}`);
}
preco(10, "BRL");

enum Moeda {
  Real = "BRL",
  Dolar = "USD",
}
function preco(valor: number, m: Moeda) {
  console.log(`Preço: ${valor} ${m}`);
}
preco(10, Moeda.Real);
preco(2, Moeda.Dolar);

Preço: 10 BRL
Preço: 2 USD

Resumo

  • enum agrupa constantes com nome; o numérico começa em 0 e funciona nos dois sentidos.
  • O enum gera um objeto no JavaScript; o const enum só some quando isolatedModules está desligado.
  • O enum de texto só aceita os próprios membros, não o texto solto.
  • Alternativa popular: union de literais (e objeto as const).
