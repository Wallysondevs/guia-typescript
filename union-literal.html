Union e Literal Types

Às vezes um valor pode ser de mais de um tipo: um código que é número ou texto. Isso é uma union, escrita com a barra | (“ou”). E às vezes o valor só pode ser uma de poucas opções exatas, como "P", "M" ou "G": são os literal types. Juntos, eles descrevem dados reais com muita precisão.

Você vai aprender
  • Union types: string | number.
  • O que dá e o que não dá para fazer com um valor de union.
  • Literal types: "pequeno" | "medio" | "grande".
  • De bônus: a interseção A & B.

1. Union: um ou outro

type Id = string | number;

function mostrarId(id: Id) {
  console.log("Seu id é: " + id);
}

mostrarId(101);
mostrarId("A-202");
$ npx tsc && node dist/union.js
Seu id é: 101
Seu id é: A-202

Um booleano, porém, não está na union:

type Id = string | number;
const id: Id = true;
$ npx tsc
src/union-erro.ts(2,7): error TS2322: Type 'boolean' is not assignable to type 'Id'.

2. Só o que é comum a todos

Com um valor string | number, o compilador só deixa usar o que existe nos dois tipos. O toUpperCase só existe em string:

function formatar(valor: string | number) {
  console.log(valor.toString());
  return valor.toUpperCase();
}
$ npx tsc
src/comum.ts(3,16): error TS2339: Property 'toUpperCase' does not exist on type 'string | number'.
  Property 'toUpperCase' does not exist on type 'number'.

O toString() passou (os dois têm); o toUpperCase() não. Para usar o que é só de um dos tipos, é preciso conferir antes. Esse é o assunto da próxima aula, Narrowing. Uma prévia:

function formatar(valor: string | number): string {
  if (typeof valor === "string") {
    return valor.toUpperCase();
  }
  return valor.toFixed(2);
}
console.log(formatar("café"));
console.log(formatar(9.5));
$ npx tsc && node dist/comum.js
CAFÉ
9.50

3. Literal types: uma lista fechada

type Tamanho = "P" | "M" | "G";
type Direcao = "norte" | "sul" | "leste" | "oeste";

function pedirCamisa(tamanho: Tamanho) {
  console.log("Camisa tamanho " + tamanho);
}

function andar(d: Direcao, passos: 1 | 2 | 3) {
  console.log(`Andando ${passos} passo(s) para o ${d}`);
}

pedirCamisa("M");
andar("norte", 2);
$ npx tsc && node dist/literal.js
Camisa tamanho M
Andando 2 passo(s) para o norte

Agora tente um tamanho fora da lista e um número de passos que não vale:

type Tamanho = "P" | "M" | "G";
function pedirCamisa(tamanho: Tamanho) {}
pedirCamisa("GG");
pedirCamisa("m");

let passos: 1 | 2 | 3 = 4;
$ npx tsc
src/literal-erro.ts(3,13): error TS2345: Argument of type '"GG"' is not assignable to parameter of type 'Tamanho'.
src/literal-erro.ts(4,13): error TS2345: Argument of type '"m"' is not assignable to parameter of type 'Tamanho'.
src/literal-erro.ts(6,5): error TS2322: Type '4' is not assignable to type '1 | 2 | 3'.

Repare que "m" minúsculo também foi recusado: literal é exato. A mensagem cita o nome do tipo (Tamanho); quando o tipo não tem nome, como em 1 | 2 | 3, ela mostra a própria lista.

4. Bônus: interseção com &

Se a union | é “ou”, a interseção & é “e”: o valor precisa ter tudo dos dois tipos.

type ComNome = { nome: string };
type ComIdade = { idade: number };
type Pessoa = ComNome & ComIdade;

const p: Pessoa = { nome: "Ana", idade: 30 };
console.log(p);

const q: Pessoa = { nome: "Duda" };
$ npx tsc
src/intersecao.ts(8,7): error TS2322: Type '{ nome: string; }' is not assignable to type 'Pessoa'.
  Property 'idade' is missing in type '{ nome: string; }' but required in type 'ComIdade'.

Quando dá errado

Um let com valor literal fica largo 
type Tamanho = "P" | "M" | "G";
function pedirCamisa(tamanho: Tamanho) {}

let escolha = "M";
pedirCamisa(escolha);
$ npx tsc
src/let-largo.ts(5,13): error TS2345: Argument of type 'string' is not assignable to parameter of type 'Tamanho'.

Lembra da aula Inferência? Um let vira string, e string é largo demais para Tamanho. Soluções: const escolha = "M" ou let escolha: Tamanho = "M".

Referência rápida

EscritaSignificado

"P" | "M" | "G"só um destes textos exatos

Missões

Missão: crie type Semaforo = "verde" | "amarelo" | "vermelho" e use no parâmetro de acao. Mostre as ações para "verde" e "vermelho".

function acao(cor: string) {
  if (cor === "verde") return "verde: siga";
  if (cor === "amarelo") return "amarelo: atenção";
  return "vermelho: pare";
}

type Semaforo = "verde" | "amarelo" | "vermelho";
function acao(cor: Semaforo) {
  if (cor === "verde") return "verde: siga";
  if (cor === "amarelo") return "amarelo: atenção";
  return "vermelho: pare";
}
console.log(acao("verde"));
console.log(acao("vermelho"));

verde: siga
vermelho: pare

Missão: com o tipo Semaforo da missão anterior, chame acao("azul") e cole o erro.

type Semaforo = "verde" | "amarelo" | "vermelho";
function acao(cor: Semaforo) {
  return cor;
}
console.log(acao("verde"));

type Semaforo = "verde" | "amarelo" | "vermelho";
function acao(cor: Semaforo) {
  return cor;
}
console.log(acao("azul"));

src/missao.ts(5,18): error TS2345: Argument of type '"azul"' is not assignable to parameter of type 'Semaforo'.

Missão: escreva function codigo(c: string | number): se for número, mostra com # e 4 dígitos ("#" + String(c).padStart(4, "0")); se for texto, mostra # e o texto em maiúsculas. Chame com 42 e "a7".

function codigo(c: any) {
  console.log("#" + c);
}
codigo(42);
codigo("a7");

function codigo(c: string | number) {
  if (typeof c === "number") {
    console.log("#" + String(c).padStart(4, "0"));
  } else {
    console.log("#" + c.toUpperCase());
  }
}
codigo(42);
codigo("a7");

#0042
#A7

Resumo

  • A | B (union): o valor é um ou outro; só dá para usar direto o que os dois têm.
  • Literal types limitam o valor a uma lista exata: "P" | "M" | "G".
  • A & B (interseção): o valor tem tudo dos dois.
  • Um let com texto vira string; use const ou a anotação para manter o literal.
