keyof e typeof

Dois operadores fazem o TypeScript tirar tipos de coisas que já existem. O keyof pega as chaves de um tipo; o typeof (usado num lugar de tipo) pega o tipo de uma variável. Juntos, eles evitam escrever a mesma informação duas vezes.

Você vai aprender
  • keyof T: a união dos nomes das propriedades.
  • typeof x em posição de tipo.
  • Acesso indexado: T["campo"] e T[keyof T].
  • O trio keyof typeof com objetos as const.

1. keyof: as chaves de um tipo

type Produto = { nome: string; preco: number; estoque: number };
type Campo = keyof Produto;

function ordenarPor(lista: Produto[], campo: Campo): Produto[] {
  return [...lista].sort((a, b) => (a[campo] > b[campo] ? 1 : -1));
}

const lista: Produto[] = [
  { nome: "Uva", preco: 9, estoque: 3 },
  { nome: "Kiwi", preco: 12, estoque: 1 },
  { nome: "Pera", preco: 7, estoque: 5 },
];
console.log(ordenarPor(lista, "preco").map((p) => p.nome));
console.log(ordenarPor(lista, "nome").map((p) => p.nome));

ordenarPor(lista, "peso");
$ npx tsc
src/keyof.ts(16,19): error TS2345: Argument of type '"peso"' is not assignable to parameter of type 'keyof Produto'.

O tipo Campo é "nome" | "preco" | "estoque" (a mensagem o chama de keyof Produto). Se alguém acrescentar um campo em Produto, o Campo acompanha sozinho. Sem a última linha:

$ npx tsc && node dist/keyof.js
[ 'Pera', 'Uva', 'Kiwi' ]
[ 'Kiwi', 'Pera', 'Uva' ]

2. typeof: o tipo de uma variável

No JavaScript, typeof roda e devolve um texto ("number"). Num lugar de tipo, o typeof do TypeScript devolve o tipo completo da variável:

const configPadrao = {
  tema: "claro",
  fonte: 16,
  atalhos: true,
};

type Config = typeof configPadrao;

function aplicar(c: Config) {
  console.log(`tema ${c.tema}, fonte ${c.fonte}`);
}
aplicar({ tema: "escuro", fonte: 18, atalhos: false });

aplicar({ tema: "escuro" });
$ npx tsc
src/typeof.ts(14,9): error TS2739: Type '{ tema: string; }' is missing the following properties from type '{ tema: string; fonte: number; atalhos: boolean; }': fonte, atalhos

O tipo Config nasceu do objeto: { tema: string; fonte: number; atalhos: boolean }. Repare que a mensagem mostra o tipo por extenso, porque ele não foi escrito à mão em lugar nenhum.

3. Acesso indexado: T["campo"]

type Pedido = {
  id: number;
  cliente: { nome: string; cidade: string };
  itens: { produto: string; qtd: number }[];
};

type Cliente = Pedido["cliente"];
type Item = Pedido["itens"][number];

const c: Cliente = { nome: "Ana", cidade: "Recife" };
const i: Item = { produto: "café", qtd: 2 };
console.log(c, i);

const teste: Pedido[keyof Pedido] = true;
$ npx tsc
src/indexado.ts(14,7): error TS2322: Type 'boolean' is not assignable to type 'number | { produto: string; qtd: number; }[] | { nome: string; cidade: string; }'.

Pedido["cliente"] é o tipo daquele campo. ["itens"][number] é “o tipo de um item do array”. E Pedido[keyof Pedido] é a união dos tipos de todos os campos, como o erro de propósito da última linha mostra.

4. keyof typeof com as const

Esta combinação aparece muito: a lista de opções existe uma vez só, como objeto de verdade, e os tipos saem dela.

const PLANOS = {
  basico: 19.9,
  plus: 39.9,
  premium: 79.9,
} as const;

type Plano = keyof typeof PLANOS;

function assinar(plano: Plano) {
  console.log(`Plano ${plano}: R$ ${PLANOS[plano]}`);
}

assinar("plus");
for (const p of Object.keys(PLANOS) as Plano[]) assinar(p);

assinar("gold");
$ npx tsc
src/keyof-typeof.ts(16,9): error TS2345: Argument of type '"gold"' is not assignable to parameter of type '"basico" | "plus" | "premium"'.

O typeof PLANOS é o tipo do objeto; o keyof desse tipo é "basico" | "plus" | "premium". Acrescentou um plano no objeto? O tipo já sabe.

Quando dá errado

keyof num valor (em vez de num tipo) 
const cores = { azul: "#00f", verde: "#0f0" };
type Cor = keyof cores;
$ npx tsc
src/keyof-valor.ts(2,18): error TS2749: 'cores' refers to a value, but is being used as a type here. Did you mean 'typeof cores'?

O keyof trabalha com tipos. Para um valor, use keyof typeof cores; a mensagem até sugere isso.

Missões

Missão: crie type Estado = keyof typeof TAXAS e use em taxa(uf: Estado). Mostre SP: 12% e RJ: 15%.

const TAXAS = { SP: 12, RJ: 15, MG: 10 } as const;
function taxa(uf: string) {
  console.log(`${uf}: ${uf}%`);
}

const TAXAS = { SP: 12, RJ: 15, MG: 10 } as const;
type Estado = keyof typeof TAXAS;
function taxa(uf: Estado) {
  console.log(`${uf}: ${TAXAS[uf]}%`);
}
taxa("SP");
taxa("RJ");

SP: 12%
RJ: 15%

Missão: crie type Opcoes = typeof padrao, tipe a constante minhas com ele e cole o erro que mostra o campo que faltou.

const padrao = { som: true, volume: 7 };
const minhas = { som: false };
console.log(minhas);

const padrao = { som: true, volume: 7 };
type Opcoes = typeof padrao;
const minhas: Opcoes = { som: false };
console.log(minhas);

src/missao.ts(3,7): error TS2741: Property 'volume' is missing in type '{ som: false; }' but required in type '{ som: boolean; volume: number; }'.

Resumo

  • keyof T é a união das chaves; acompanha o tipo sozinho.
  • typeof x, num lugar de tipo, é o tipo da variável.
  • T["campo"], T[number] e T[keyof T] leem tipos de dentro de outros.
  • keyof typeof obj + as const: uma lista de opções, uma fonte só.
