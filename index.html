Aprenda TypeScript, o JavaScript com tipos, do zero, como numa escola: cada assunto é explicado pedaço por pedaço e você vê a resposta de verdade do compilador tsc e do Node. Nenhuma saída foi inventada e nenhuma mensagem de erro foi traduzida.

O que é este guia

O TypeScript é o JavaScript com uma camada a mais: os tipos. Você diz que uma variável guarda um número, que uma função recebe um texto, que um objeto tem tais campos, e o compilador confere tudo antes de o programa rodar. Muitos erros que só apareceriam na tela do usuário aparecem no seu terminal.

O guia é para quem já viu o básico de JavaScript (variáveis, if, funções, arrays e objetos). Se ainda não viu, comece pelo Guia JavaScript e volte depois. Cada aula ensina um assunto só. Os exemplos acompanham a Ana, que estuda num computador fictício chamado notebook, com o projeto na pasta /home/ana/projeto.

O texto está em português do Brasil. As palavras do TypeScript ficam como a linguagem as escreve (interface, type, extends), e a gente explica o termo na primeira vez. As mensagens do compilador não são traduzidas: aparecem exatamente como o tsc mostrou, em inglês, com a explicação em português logo depois.

Versões usadas

Todas as saídas foram colhidas com TypeScript 7.0.2 e Node.js 24.22.1, num projeto criado com npx tsc --init. Com outras versões, o texto de algumas mensagens pode mudar um pouco, mas o código do erro (como TS2322) costuma ser o mesmo.

Como estudar

Programação se aprende programando. Para cada aula, siga estes quatro passos:

  1. Leia com calma. Leia a ideia, o código e a saída. Não pule a parte “Quando dá errado”: ler erros é metade do trabalho com TypeScript.
  2. Digite os exemplos. Crie os arquivos em src/, rode npx tsc e depois o node. Compare com a saída da aula.
  3. Faça as missões e os exercícios. Nas caixas Missão, você escreve o código, roda no seu terminal e cola a saída para conferir. Tente de verdade antes de abrir a solução.
  4. Quebre de propósito. Troque um tipo, apague uma linha, veja o que o compilador diz. É assim que as mensagens ficam familiares.
