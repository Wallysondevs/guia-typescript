Narrowing (Estreitamento)

Quando um valor pode ser de vários tipos (uma union), você confere qual ele é com um if. O TypeScript acompanha essa conferência: dentro do bloco, o tipo fica mais estreito. Isso se chama narrowing, e é o que torna as unions práticas.

Você vai aprender
  • A estreitar com typeof, ===, Array.isArray, in e instanceof.
  • Que o retorno antecipado também estreita o resto da função.
  • A ver o tipo estreitado num erro de propósito.

A ideia: o funil

Imagine um funil. No topo entra string | number | null. Cada if separa um caso: “se for null, saia”; “se for string, faça isto”. O que sobra lá embaixo tem um tipo só, e o compilador sabe qual.

1. typeof

function dobrar(x: string | number) {
  if (typeof x === "string") {
    return x.repeat(2);
  }
  return x * 2;
}
console.log(dobrar("ab"));
console.log(dobrar(21));
$ npx tsc && node dist/typeof.js
abab
42

Depois do if com return, o compilador sabe que só sobrou number, por isso o x * 2 passa. Para ver o tipo em cada ponto, provoque erros de propósito:

function revelar(x: string | number | boolean) {
  if (typeof x === "string") {
    const a: null = x;
  } else if (typeof x === "number") {
    const b: null = x;
  } else {
    const c: null = x;
  }
}
$ npx tsc
src/revela.ts(3,11): error TS2322: Type 'string' is not assignable to type 'null'.
src/revela.ts(5,11): error TS2322: Type 'number' is not assignable to type 'null'.
src/revela.ts(7,11): error TS2322: Type 'boolean' is not assignable to type 'null'.

Em cada bloco, o mesmo x tem um tipo diferente: string, number e, no else, só sobrou boolean.

2. Igualdade e “é verdadeiro?”

function saudar(nome: string | null | undefined) {
  if (nome === null) {
    return "nome apagado";
  }
  if (!nome) {
    return "sem nome";
  }
  return "Olá, " + nome.toUpperCase();
}
console.log(saudar("ana"));
console.log(saudar(null));
console.log(saudar(undefined));
console.log(saudar(""));
$ npx tsc && node dist/igualdade.js
Olá, ANA
nome apagado
sem nome
sem nome

O if (!nome) pega undefined e também o texto vazio "", que é “falso” no JavaScript. Cuidado com isso quando 0 ou "" forem valores válidos.

3. Array.isArray, in e instanceof

function total(x: number | number[]) {
  if (Array.isArray(x)) {
    return x.reduce((a, b) => a + b, 0);
  }
  return x;
}
console.log(total(5), total([1, 2, 3]));

type Carro = { rodas: number; dirigir(): string };
type Barco = { velas: number; navegar(): string };

function mover(v: Carro | Barco) {
  if ("rodas" in v) {
    return v.dirigir();
  }
  return v.navegar();
}
console.log(mover({ rodas: 4, dirigir: () => "vrum" }));
console.log(mover({ velas: 2, navegar: () => "splash" }));

Quando dá errado

typeof null é "object" 
function tamanho(x: string[] | null) {
  if (typeof x === "object") {
    return x.length;
  }
  return 0;
}
$ npx tsc
src/typeof-null.ts(3,12): error TS18047: 'x' is possibly 'null'.

Uma esquisitice antiga do JavaScript: typeof null também é "object". O compilador sabe disso e avisa que x ainda pode ser null. Use if (x !== null) ou if (x).

Guardar a conferência numa variável 
function primeiraLetra(x: string | number) {
  const ehTexto = typeof x === "string";
  if (ehTexto) {
    return x.charAt(0);
  }
  return "";
}
console.log(primeiraLetra("Ana"));
$ npx tsc && node dist/sem-narrowing.js
A

Aqui funcionou: guardar a conferência numa const também estreita, desde que a variável não seja reatribuída entre a conferência e o uso. Se ainda assim o compilador não entender, confira direto no if.

Missão: escreva function contar(x: string | string[]) que mostra 3 itens para ["a", "b", "c"] e 1 item para um texto solto. Use Array.isArray.

function contar(x: string | string[]) {
  console.log(x.length + " itens");
}
contar(["a", "b", "c"]);
contar("abc");

function contar(x: string | string[]) {
  if (Array.isArray(x)) {
    console.log(x.length + " itens");
  } else {
    console.log("1 item");
  }
}
contar(["a", "b", "c"]);
contar("abc");

Missão: com os tipos Cachorro e Gato, escreva function falar(a: Cachorro | Gato) usando "latir" in a para chamar o método certo. Mostre Au au! e Miau!.

type Cachorro = { latir(): string };
type Gato = { miar(): string };

function falar(a: Cachorro | Gato) {
  return a.latir();
}

type Cachorro = { latir(): string };
type Gato = { miar(): string };

function falar(a: Cachorro | Gato) {
  if ("latir" in a) {
    return a.latir();
  }
  return a.miar();
}
console.log(falar({ latir: () => "Au au!" }));
console.log(falar({ miar: () => "Miau!" }));

Resumo

  • Narrowing: o compilador estreita o tipo dentro de cada bloco de conferência.
  • Ferramentas: typeof, ===, verdadeiro/falso, Array.isArray, in, instanceof.
  • Um return antecipado estreita o resto da função.
  • typeof null é "object": confira o null à parte.
