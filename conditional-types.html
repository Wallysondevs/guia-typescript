Conditional Types

E se um tipo pudesse tomar uma decisão? “Se T for texto, use isto; senão, aquilo”. É o que fazem os conditional types, com a mesma cara do operador ternário do JavaScript: T extends U ? X : Y.

Você vai aprender
  • A forma T extends U ? X : Y.
  • Conditional types com generics em funções.
  • Distribuição sobre unions (e como o Exclude funciona).
  • Como desligar a distribuição.

1. A forma básica

type EhTexto<T> = T extends string ? "sim" : "não";

const a: EhTexto<string> = "sim";
const b: EhTexto<number> = "não";
const c: EhTexto<"olá"> = "sim";
console.log(a, b, c);

const d: EhTexto<boolean> = "sim";
$ npx tsc
src/condicional.ts(8,7): error TS2322: Type '"sim"' is not assignable to type '"não"'.
T extends string
a pergunta: “T cabe em string?”. "olá" cabe (é um tipo de texto mais específico).
? "sim" : "não"
o resultado de cada lado.

EhTexto<boolean> virou "não", então "sim" foi recusado.

2. Na prática: o tipo de saída depende da entrada

type Embalado<T> = T extends unknown[] ? T : T[];

function emLista<T>(valor: T): Embalado<T> {
  return (Array.isArray(valor) ? valor : [valor]) as Embalado<T>;
}

const x = emLista(5);
const y = emLista(["a", "b"]);
const x2: number[] = x;
const y2: string[] = y;
console.log(x2, y2);

const errado: string = emLista(5);
$ npx tsc
src/pratica.ts(13,7): error TS2322: Type 'number[]' is not assignable to type 'string'.

emLista(5) devolve number[] e emLista(["a","b"]) devolve string[] (sem virar lista de listas). Repare no as Embalado<T>: dentro da função, o TypeScript não consegue provar sozinho qual lado do condicional vale, então usamos uma asserção.

3. Distribuição sobre unions

Quando T é uma union, o condicional é aplicado em cada membro separadamente e os resultados se juntam. É assim que o Exclude e o NonNullable funcionam:

type MeuExclude<T, U> = T extends U ? never : T;
type SemNulos<T> = T extends null | undefined ? never : T;

type Status = "ativo" | "inativo" | "banido";
type Permitido = MeuExclude<Status, "banido">;

const ok: Permitido = "ativo";
const ok2: SemNulos<string | null | undefined> = "texto";
console.log(ok, ok2);

const er: Permitido = "banido";
const er2: SemNulos<string | null> = null;
$ npx tsc
src/distribui.ts(11,7): error TS2322: Type '"banido"' is not assignable to type 'Permitido'.
src/distribui.ts(12,7): error TS2322: Type 'null' is not assignable to type 'string'.

Passo a passo de MeuExclude<Status, "banido">: "ativo" → "ativo"; "inativo" → "inativo"; "banido" → never. Juntando, never some e fica "ativo" | "inativo".

4. Desligando a distribuição

Às vezes você quer testar a union inteira. Envolva os dois lados em colchetes:

type Distribui<T> = T extends string ? "texto" : "outro";
type Inteiro<T> = [T] extends [string] ? "texto" : "outro";

const a: Distribui<string | number> = "outro";
const b: Distribui<string | number> = "texto";
const c: Inteiro<string | number> = "outro";
const d: Inteiro<string | number> = "texto";
console.log(a, b, c);
$ npx tsc
src/colchetes.ts(7,7): error TS2322: Type '"texto"' is not assignable to type '"outro"'.

Distribui<string | number> é "texto" | "outro" (aceita os dois). Inteiro<string | number> perguntou sobre a union toda, que não cabe em string: só "outro".

Quando dá errado

Devolver um dos lados sem asserção 
type Rotulo<T> = T extends number ? "número" : "outro";

function rotulo<T>(v: T): Rotulo<T> {
  return typeof v === "number" ? "número" : "outro";
}
$ npx tsc
src/sem-assercao.ts(4,34): error TS2322: Type '"número"' is not assignable to type 'Rotulo<T>'.
src/sem-assercao.ts(4,45): error TS2322: Type '"outro"' is not assignable to type 'Rotulo<T>'.

O narrowing de v não muda o tipo genérico T, então o TypeScript não aceita nenhum dos lados. Saídas: usar as Rotulo<T> no retorno, ou trocar o condicional por sobrecargas (aula de sobrecarga).

Referência rápida

EscritaSignificado
T extends U ? X : Yse T cabe em U, X; senão Y
T extends U ? never : Tremove membros (o Exclude)
[T] extends [U] ? …testa a union inteira, sem distribuir

Resumo

  • T extends U ? X : Y é um “if” de tipos.
  • Com unions, o condicional distribui; never some do resultado.
  • Exclude e NonNullable são conditional types.
  • [T] extends [U] desliga a distribuição.
