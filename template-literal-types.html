Template Literal Types

Você já usa crases para montar textos no JavaScript: `olá, ${nome}`. O TypeScript aceita a mesma ideia nos tipos: dá para descrever “um texto que começa com #”, “px ou rem depois de um número” ou gerar todos os nomes de eventos de uma lista.

Você vai aprender
  • A sintaxe `prefixo-${Tipo}` em tipos.
  • Combinação automática de unions.
  • Uppercase, Lowercase, Capitalize e Uncapitalize.
  • Extrair partes de um texto com infer.

1. Um padrão de texto

type CorHex = `#${string}`;
type Medida = `${number}px` | `${number}rem`;

const cor: CorHex = "#ff8800";
const largura: Medida = "320px";
const fonte: Medida = "1.5rem";
console.log(cor, largura, fonte);

const corErrada: CorHex = "ff8800";
const medidaErrada: Medida = "20pt";
$ npx tsc
src/padrao.ts(9,7): error TS2322: Type '"ff8800"' is not assignable to type '`#${string}`'.
src/padrao.ts(10,7): error TS2322: Type '"20pt"' is not assignable to type 'Medida'.
`#${string}`
qualquer texto que comece com #.
`${number}px`
um número seguido de px: "320px" e "1.5px" servem; "abcpx" não.

2. Unions se multiplicam

Com unions dentro do template, o TypeScript gera todas as combinações:

type Tamanho = "p" | "m" | "g";
type Cor = "azul" | "preto";
type Sku = `${Cor}-${Tamanho}`;

const todos: Sku[] = ["azul-p", "azul-m", "azul-g", "preto-p", "preto-m", "preto-g"];
console.log(todos.length, "combinações");

const errado: Sku = "verde-p";
$ npx tsc
src/combina.ts(8,7): error TS2322: Type '"verde-p"' is not assignable to type '"azul-g" | "azul-m" | "azul-p" | "preto-g" | "preto-m" | "preto-p"'.

A mensagem lista as 6 combinações: 2 cores × 3 tamanhos.

3. Mudando maiúsculas e minúsculas

type Evento = "click" | "focus";
type Handler = `on${Capitalize<Evento>}`;
type Constante = Uppercase<Evento>;

const h: Handler = "onClick";
const k: Constante = "FOCUS";
const l: Lowercase<"OLÁ"> = "olá";
const u: Uncapitalize<"Nome"> = "nome";
console.log(h, k, l, u);

const errado: Handler = "onclick";
$ npx tsc
src/caixa.ts(11,7): error TS2820: Type '"onclick"' is not assignable to type '"onClick" | "onFocus"'. Did you mean '"onClick"'?

Juntando com mapped types (aula anterior), você gera objetos inteiros com nomes derivados, como onClick e onFocus.

4. Extraindo partes com infer

type Rota = "/usuarios/:id" | "/produtos/:codigo";
type Param<R> = R extends `${string}/:${infer P}` ? P : never;

const p1: Param<"/usuarios/:id"> = "id";
const p2: Param<Rota> = "codigo";
console.log(p1, p2);

const p3: Param<Rota> = "nome";
$ npx tsc
src/extrair.ts(8,7): error TS2322: Type '"nome"' is not assignable to type '"codigo" | "id"'.

Param<Rota> virou "id" | "codigo": o nome depois do : em cada rota.

Quando dá errado

Um texto montado em tempo de execução

Um texto comum (string) não é garantidamente `#${string}`, mesmo que você saiba que começa com #:

type CorHex = `#${string}`;
function pintar(c: CorHex) {
  console.log("pintando", c);
}
let codigo = "ff0000";
const cor = "#" + codigo;
pintar(cor);
$ npx tsc
src/montado.ts(7,8): error TS2345: Argument of type 'string' is not assignable to parameter of type '`#${string}`'.

A soma "#" + codigo é só string para o TypeScript. Use um template no valor: const cor = `#${codigo}` as const; ou anote const cor: CorHex = `#${codigo}`;.

Referência rápida

EscritaAceita
`#${string}`texto que começa com #
`${number}px`número + px
`${A}-${B}`todas as combinações das unions

Missões

Missão: crie type Preco = `${Moeda}${number}` (moeda seguida de número) para o código compilar. Saída esperada: BRL10 USD2.5.

type Moeda = "BRL" | "USD";
type Preco = Moeda;
const a: Preco = "BRL10";
const b: Preco = "USD2.5";
console.log(a, b);

type Moeda = "BRL" | "USD";
type Preco = `${Moeda}${number}`;
const a: Preco = "BRL10";
const b: Preco = "USD2.5";
console.log(a, b);

BRL10 USD2.5

Missão: escreva type Getter = `get${Capitalize<Campo>}` para os nomes compilarem. Saída esperada: getNome getEmail.

type Campo = "nome" | "email";
type Getter = `get${Campo}`;
const g1: Getter = "getNome";
const g2: Getter = "getEmail";
console.log(g1, g2);

type Campo = "nome" | "email";
type Getter = `get${Capitalize<Campo>}`;
const g1: Getter = "getNome";
const g2: Getter = "getEmail";
console.log(g1, g2);

getNome getEmail

Resumo

  • Crases também funcionam em tipos: `#${string}`, `${number}px`.
  • Unions dentro do template geram todas as combinações.
  • Uppercase, Lowercase, Capitalize e Uncapitalize mudam as letras.
  • infer extrai partes de um texto.
