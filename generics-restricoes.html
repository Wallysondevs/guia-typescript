Restrições em Generics (extends)

Um T sem regras pode ser qualquer coisa, então quase nada pode ser feito com ele. Com T extends Algo, você diz “T pode ser qualquer tipo, desde que tenha isto”. A função continua genérica, mas agora pode usar o que a restrição garante.

Você vai aprender
  • A restringir com <T extends { length: number }>.
  • O par famoso <T, K extends keyof T>, para ler propriedades com segurança.
  • Valores padrão para parâmetros de tipo: <T = string>.

1. T extends: “qualquer um que tenha…”

function maisLongo<T extends { length: number }>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}

console.log(maisLongo("banana", "kiwi"));
console.log(maisLongo([1, 2], [1, 2, 3]));
$ npx tsc && node dist/restricao.js
banana
[ 1, 2, 3 ]

Textos e arrays têm length, então servem. Um número não tem:

function maisLongo<T extends { length: number }>(a: T, b: T): T {
  return a.length >= b.length ? a : b;
}
maisLongo(10, 20);
$ npx tsc
src/restricao-erro.ts(4,11): error TS2345: Argument of type 'number' is not assignable to parameter of type '{ length: number; }'.

2. Restringindo com uma interface

interface ComId {
  id: number;
}

function buscarPorId<T extends ComId>(lista: T[], id: number): T | undefined {
  return lista.find((item) => item.id === id);
}

const usuarios = [
  { id: 1, nome: "Ana" },
  { id: 2, nome: "Duda" },
];
const u = buscarPorId(usuarios, 2);
console.log(u?.nome);
$ npx tsc && node dist/interface.js
Duda

Repare: a função só sabe que cada item tem id, mas o resultado mantém o tipo completo, com nome. Esse é o ganho sobre escrever lista: ComId[], que perderia o nome. (O ?. lê o campo só se u existir; aula null, undefined e ?..)

3. K extends keyof T

O keyof T é a união dos nomes das propriedades de T (detalhes na aula keyof e typeof). Com ele dá para escrever uma função que lê qualquer propriedade, sem errar o nome:

function pegar<T, K extends keyof T>(obj: T, chave: K): T[K] {
  return obj[chave];
}

const livro = { titulo: "Iracema", ano: 1865 };
const t = pegar(livro, "titulo");
const a = pegar(livro, "ano");
console.log(t.toUpperCase(), a + 1);

pegar(livro, "autor");
$ npx tsc
src/keyof.ts(10,14): error TS2345: Argument of type '"autor"' is not assignable to parameter of type '"ano" | "titulo"'.

O retorno T[K] é o tipo daquela propriedade: string para "titulo", number para "ano". E uma chave que não existe é recusada, mostrando as que valem.

4. Valor padrão do parâmetro de tipo

type Evento<Dados = string> = {
  nome: string;
  dados: Dados;
};

const e1: Evento = { nome: "login", dados: "ana" };
const e2: Evento<{ x: number; y: number }> = { nome: "clique", dados: { x: 10, y: 20 } };
console.log(e1.dados.toUpperCase(), e2.dados.x);
$ npx tsc && node dist/padrao.js
ANA 10

Sem dizer o tipo, Evento usa o padrão, string.

Quando dá errado

Objeto que não cumpre a restrição 
interface ComId { id: number }
function salvar<T extends ComId>(item: T) {
  return item.id;
}
salvar({ nome: "Ana" });
$ npx tsc
src/sem-id.ts(5,10): error TS2353: Object literal may only specify known properties, and 'nome' does not exist in type 'ComId'.

O objeto não tem id, então não cumpre a restrição. A mensagem aponta o campo que não cabe em ComId (o nome); com { id: 1, nome: "Ana" } a chamada passa.

Referência rápida

EscritaSignificado
<T extends { length: number }>T precisa ter length
<T extends ComId>T precisa ter o que a interface pede
<T, K extends keyof T>K é um dos nomes de propriedade de T
T[K]o tipo da propriedade K de T
<T = string>T vale string se ninguém disser outro

Missões

Missão: escreva function somarPrecos<T extends { preco: number }>(itens: T[]): number e mostre Total: 35 para [{ nome: "pão", preco: 10 }, { nome: "café", preco: 25 }].

function somarPrecos(itens: any[]): number {
  return 0;
}

function somarPrecos<T extends { preco: number }>(itens: T[]): number {
  let total = 0;
  for (const i of itens) total += i.preco;
  return total;
}
console.log("Total: " + somarPrecos([{ nome: "pão", preco: 10 }, { nome: "café", preco: 25 }]));

Total: 35

Missão: escreva function ler<T, K extends keyof T>(obj: T, chave: K): T[K] e mostre ler(pessoa, "nome") e ler(pessoa, "idade") para { nome: "Duda", idade: 28 }.

function ler(obj: any, chave: string) {
  return obj[chave];
}
const pessoa = { nome: "Duda", idade: 28 };

function ler<T, K extends keyof T>(obj: T, chave: K): T[K] {
  return obj[chave];
}
const pessoa = { nome: "Duda", idade: 28 };
console.log(ler(pessoa, "nome"));
console.log(ler(pessoa, "idade"));

Duda
28

Resumo

  • T extends X restringe o genérico: só tipos que tenham o que X pede.
  • K extends keyof T e o retorno T[K] leem propriedades com segurança.
  • <T = string> dá um padrão ao parâmetro de tipo.
